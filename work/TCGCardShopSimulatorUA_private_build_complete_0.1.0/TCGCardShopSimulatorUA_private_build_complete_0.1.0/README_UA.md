# Українська локалізація TCG Card Shop Simulator

Версія локалізації: **0.1.0**  
Статус: словник пройшов статичну перевірку; повний runtime smoke-test ще не виконано.

## Встановлення через інсталятор

Після появи зібраного `TCGCardShopSimulatorUA-Installer.exe`:

1. Закрийте **TCG Card Shop Simulator**.
2. Запустіть інсталятор.
3. Натисніть **«Знайти у Steam»** або вручну виберіть кореневу папку гри.
4. Інсталятор перевіряє наявність:
   - `Card Shop Simulator.exe`
   - `Card Shop Simulator_Data\`
5. Натисніть **«Встановити / Оновити»** і перегляньте список файлів, які буде змінено.
6. Запустіть гру та в налаштуваннях мови виберіть **«Українська»**.

Інсталятор не повинен змінювати збереження, Steam-файли чи оригінальні Unity-асети гри. Якщо він замінює вже наявний керований runtime-файл, перед записом створюється backup.

## Ручне встановлення словника

Цей спосіб підходить, якщо **Translator 1.0.3** і сумісний BepInEx уже встановлені.

Скопіюйте:

```text
localization_data.txt
```

у:

```text
TCG Card Shop Simulator\BepInEx\plugins\Translator\localization_data.txt
```

Після запуску гри виберіть **«Українська»** у мовних налаштуваннях.

> `Translator.dll` не входить до публічного source/localization пакета. Автор Translator дозволяє ділитися власним `localization_data.txt` на Nexus, але використання самого `Translator.dll` у чужому файлі/моді потребує окремого дозволу.

## Оновлення

Для нової версії локалізації повторно запустіть інсталятор і оберіть **«Встановити / Оновити»**. Інсталятор перевіряє SHA-256 керованих файлів. Якщо файл був змінений вручну після попередньої інсталяції, автоматичне оновлення має зупинитися замість тихого перезапису.

## Видалення

1. Закрийте гру.
2. Запустіть той самий інсталятор.
3. Оберіть папку гри.
4. Натисніть **«Видалити»**.

Видаляються лише файли з ownership manifest цієї локалізації. Якщо до встановлення файл уже існував, інсталятор відновлює його backup. Якщо керований файл після встановлення був змінений користувачем, інсталятор залишає його на місці та повідомляє про ручне вирішення.

## Якщо переклад не з’явився

Перевірте:

- у грі вибрано **«Українська»**;
- `BepInEx\plugins\Translator\Translator.dll` присутній;
- `BepInEx\plugins\Translator\localization_data.txt` присутній;
- у `BepInEx\config\shaklin.Translator.cfg` встановлено `ENABLED = true`.

Лог BepInEx:

```text
TCG Card Shop Simulator\BepInEx\LogOutput.log
```

У робочому baseline Translator 1.0.3 успішно завантажував словник, але фінальний український словник у грі в цьому середовищі ще не запускався.

## Якщо замість українських літер квадрати або дивні символи

Перевірка `Ї ї Є є І і Ґ ґ` у runtime ще обов’язкова. Не встановлюйте випадковий шрифт поверх гри. Translator 1.0.3 підтримує власні шрифти `FredokaOne-Regular.ttf/.otf` та `LiberationSans.ttf/.otf`, але додавати їх до релізу слід лише після фактичного тесту гліфів і перевірки ліцензії конкретного font-файлу.

## Сумісність

Підготовлено для перевіреного baseline:

- Windows x64;
- Unity `2021.3.38.8007589`;
- BepInEx `5.4.23.5`;
- Translator `1.0.3` (`shaklin.Translator`).

Точний Steam build ID гри не був присутній у переданому `BepInEx.zip`, тому сумісність із майбутніми оновленнями гри треба перевіряти після кожного великого патча.

## Публікація

Сам словник можна готувати як окремий translation-файл. Перед публікацією one-file інсталятора потрібно:

- отримати дозвіл Shaklin на включення `Translator.dll`;
- перевірити політику розробника гри щодо модів/локалізацій;
- додати лише законно розповсюджувані runtime-файли;
- виконати runtime smoke-test і перевірку кириличних гліфів.
