Оберіть відділення або поштомат.

Після «Зберегти адресу» або «Пропустити» — перехід у кабінет (A-Hub), з одноразовим тостом «Акаунт створено» (див. A-Register-Done).

Примітка до макета · Реєстрація, крок 2 (RD-20)
  • Крок можна пропустити (затверджено, Q3). Для QA: окремо пройти реєстрацію без адреси — «Пропустити» → кабінет, акаунт без адрес, оформлення замовлення працює як для нового покупця.
  • Зміни власника 29.10: імʼя та прізвище на цьому кроці не показуються — беруться з кроку 1 (рядок «Отримувач»). Порядок: Область → Місто → Відділення / поштомат → блок «Адресна доставка» (Вулиця; Будинок + Квартира; По батькові, необовʼязково). Поле «Країна» прибрано.
  • Для виконавця: перед реалізацією перевірити, як модуль Нової пошти приймає адресну доставку і як вона зберігається в адресі OpenCart (одне поле чи окремі; куди лягає по батькові). Окремі поля Вулиця / Будинок / Квартира — лише якщо модуль і збереження це коректно підтримують; інакше — стоп і питання власнику.
  • Для виконавця: імʼя та прізвище з кроку 1 мають записатися в адресу (одержувач) без повторного введення.
  • Форма — жива форма Нової пошти з RD-17 у вигляді A-Addresses-Open; поведінку полів (пошук міста, список відділень) не змінюємо. Тексти помилок — з живої форми.
  • Для виконавця: перехід після кроку 1 саме на цей крок (а не на стандартну сторінку успіху OpenCart) — підтвердити, що це лише зміна переадресації, без нової логіки збереження.
