## 4. What to change
**Поведінка (JS):**
- Для кожної з п’яти дій зібрати той самий URL, який зараз дає стоковий модуль (`filter=…`, `sort`, `order`, `page`, `limit`). Виконати `fetch`, із відповіді взяти контейнер сітки, пагінацію і кількість товарів, замінити їх на сторінці, потім `history.pushState`. `popstate` повторює fetch для `location.href`.
- Новий запит скасовує попередній (`AbortController`).
- Будь-яка помилка (мережа, статус ≠ 200, у відповіді немає контейнера) → `location.href = url`.
- Стан панелі (відкрита / які групи розгорнуті) не скидати. Панель не перемальовувати.
- Під час запиту: клас завантаження на сітці (opacity .45, `pointer-events:none`), смужка 3 px `--bs-blue`, `aria-busy="true"`, `min-height` сітки = поточна висота, після вставки зняти.

**Розмітка (twig):**
- Рядок чипів — останній елемент картки шапки категорії, після панелі. Порядок і копія — нотатка §2, §4.
- Липка кнопка «Показати N товарів» нижче 992, тільки коли панель відкрита (нотатка §3).
- Низ панелі від 992: «Знайдено N товарів» + «Згорнути».
- Порожній стан замість сітки (нотатка §3, §4).
- Прихований `role="status" aria-live="polite"`, фокус-логіка (нотатка §5).
- Множина «товар/товари/товарів» у JS — правило з нотатки §4.

**CSS:** нові класи лише в `boostershop-ds.css` (секція шапки категорії), тільки токени `--bs-*`. Зелений у цій зоні не використовувати. Перемикач список/сітка лишається прихованим.

## 7. Acceptance criteria
1. `/pokemon` (1440): галочка «Бустер» не перезавантажує сторінку (у Network один fetch document-запит, немає navigation). Панель лишається відкритою, сітка оновлена, URL в адресному рядку = URL, який видав би стоковий модуль.
2. Після «Бустер» + «Японія» кількість у шапці дорівнює кількості в стоковій версії за тим самим URL (порівняти з відкриттям URL у новій вкладці).
3. Чипи: видно при закритій панелі. «×» прибирає одне значення. «Скинути все» з’являється від 2 значень. Чипи переносяться на новий рядок, горизонтального скролу немає.
4. 390: липка «Показати N товарів» видна, коли панель відкрита. Тап закриває панель, прокручує до сітки, `aria-expanded="false"` на «Фільтр».
5. Порожній результат показує картку «Нічого не знайдено з цими фільтрами» і «Скинути фільтри».
6. Back/Forward відновлює попередній фільтр без перезавантаження. Скопійований URL у новій вкладці відкриває той самий стан (серверний рендер).
7. Під час запиту шапка і панель не зсуваються (без layout shift). Сітка тьмяніє, видно смужку.
8. Помилка (DevTools → Offline, галочка) → звичайне перезавантаження за URL фільтра.
9. Скрінрідер/DOM: `role="status"` отримує «Знайдено N …» після відповіді. Фокус після «×» відповідає нотатці §5.
10. View-source сторінки з фільтром: canonical і meta robots ідентичні до/після патча.
11. Консоль без нових помилок. Тапи ≥ 44 px на 390.
