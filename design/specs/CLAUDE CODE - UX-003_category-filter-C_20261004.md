## 1. Task ID
`UX-003` (етап 3, тема «Фільтр категорії», варіант **C · фінал**)

## 2. Context
Зараз фільтр — стоковий Bootstrap у `column_right` (Font Awesome, блакитна кнопка «Пошук»). Модуль уже застосовує фільтр при зміні галочки (~250 мс), тож кнопка «Пошук» зайва. Колонка `d-md-block` показується з 768, а мобільна кнопка «Фільтр» у `category-action-toolbar` — до 991; на 768–991 видно обидві.
Дизайн-джерело (погоджено 04.10.2026): `UX-003 UX-005 UX-009 - етап 3.html` → «Фільтр категорії» → «C · фінал», ширини 1440 / 768 / 390, перемикач «Панель» (`FilterFinal` у `ux-b-stage3.jsx`, стилі `.ff-*` у тому ж HTML).

**Блокер:** шаблону модуля фільтра (`extension/…/filter.twig`) немає в evidence. Виконавець зобов’язаний знайти його в дереві й підтвердити розмітку **до** написання патча.

## 3. Goal
Одна кнопка «Фільтр» у ряду з підкатегоріями й сортуванням; вона розгортає панель з усіма групами, кожну групу можна згорнути окремо; бічної колонки немає.

## 4. What to change
**Ряд у шапці категорії (`ff-row`):** підкатегорії (наявні чипи) | кнопка «Фільтр» | сортування (`#input-sort`).
- 1440: усе в один ряд, підкатегорії в сегменті `--bs-line-2`, інструменти праворуч, сортування 220 px.
- 768: той самий ряд; підкатегорії — горизонтальна прокрутка без скролбару; «Фільтр» з текстом, сортування 200 px.
- 390: підкатегорії прокручуються; «Фільтр» і сортування — квадратні кнопки 44×44 з іконками (сортування — нативний `<select>` прозорим шаром поверх іконки, `#input-sort` без змін; `aria-label`).

**Кнопка «Фільтр»:** secondary h44, іконка повзунків, «Фільтр», лічильник вибраних значень (кругла плашка `--bs-blue`), шеврон. `aria-expanded`, `aria-controls`. Відкрита — `--bs-blue-soft`, рамка/текст `--bs-blue`.

**Панель (`ff-panel`):** всередині картки шапки категорії, під рядом, верхня лінія `--bs-line`.
- Групи модуля фільтра (зараз «Тип товару», «Країна»; кількість динамічна) — кожна з кнопкою-заголовком 48 px (назва + лічильник + шеврон, `aria-expanded`), що згортає/розгортає її чекбокси.
- Колонки груп: 390 — 1, 768 — 2, ≥1024 — 4.
- Початковий стан: на 390 відкрита лише перша група; на ≥768 — усі відкриті.
- Чекбокси 18 px, вибраний — `--bs-blue` з білою галочкою, рядок 36 px.
- Низ панелі: чипи вибраних (UX-004, «Фільтр: Бустер ×»), «Скинути», кнопка «Згорнути».
- Коли панель згорнута, а щось вибрано — чипи UX-004 під рядом.
- Кнопки «Пошук» немає (`#button-filter` лишається в DOM, прихований), фільтр застосовується при зміні, як зараз.

**Розмітка сторінки:** `column_right` на сторінці категорії більше не виводиться збоку; його вміст (модуль фільтра) рендериться в панель. Мобільна кнопка «Фільтр» з `category-action-toolbar` прибирається — її роль виконує нова кнопка. Сітка товарів на ≥1024 — 4 колонки (була 3 з колонкою).
