# Замовлення прийнято — нотатки

**На відміну від решти 5 контентних сторінок, ця НЕ редагується в адмінці.**
Вона рендериться шаблоном `templates/checkout-success.twig` з динамічними
даними з контролера `catalog/controller/checkout/success.php`.

## Що передає контролер

Поточний OpenCart 4 контролер передає тільки:
- `breadcrumbs`
- `text_message` (загальне «Дякуємо за замовлення»)

Цього **недостатньо.** Розширити контролер так, щоб він додавав:

| Змінна | Тип | Приклад |
|---|---|---|
| `order_id` | string | `"BS-2026-04812"` |
| `items` | array | `[{ title, qty, sum }, ...]` |
| `total` | string | `"700"` (вже відформатовано через `currency->format`) |
| `shipping_method` | string | `"Нова пошта — у відділення №31, Дніпро"` |
| `payment_method` | string | `"Оплата карткою"` |
| `history_url` | string | `/account/order` |
| `catalog_url` | string | `/` |
| `account_url` | string | `/account` |

Приклад розширення PHP — у коментарі в кінці `templates/checkout-success.twig`.

## Статичні елементи (не міняти без узгодження з дизайнером)

- **Заголовок hero:** `Дякуємо, замовлення в грі.`
- **Lede:** `Уже збираємо ваш лут. Статус замовлення можна перевірити в [історії замовлень].`
  - Слово «історії замовлень» — посилання на `{{ history_url }}`.
- **Часова шкала (3 кроки):**
  1. Збираємо ваш лут
  2. Пакуємо та відправляємо
  3. Надсилаємо фіскальний чек
- **Callout «Без зайвих дзвінків»:** текст у шаблоні (статичний).
- **Кнопки внизу timeline:**
  - `Продовжити покупки →` → `{{ catalog_url }}` (primary, зелена)
  - `Перейти в кабінет` → `{{ account_url }}` (secondary)

## Що звірити перед публікацією

- [ ] Контролер дійсно передає всі 8 змінних. Якщо session не має `order_id`
      (рідкісний edge-case — пряме відкриття `/checkout/success`) — додати
      fallback на старий `{{ text_message }}` через `{% if order_id is defined %}`.
- [ ] Формат `order_id` (`"BS-2026-NNNNN"`) узгоджений з адміном і фіскальним
      чеком. Якщо в системі ID просто число (наприклад `1234`) — обережно з
      форматуванням: воно не має конфліктувати з номером в адмінці.
- [ ] Currency formatter дає коректний знак гривні. У шаблоні зараз `₴{{ total }}` —
      якщо `currency->format` вже додає знак, треба прибрати `₴`.
- [ ] Sticky-aside (`.bs-cp-summary`) не лізе за межі при дуже довгих назвах
      товарів — є `-webkit-line-clamp: 2`.
