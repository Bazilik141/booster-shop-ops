# UX-003 runner 9 + BUG-004 A — нотатка для Claude Code

Дата: 2026-10-06 · Макет: `UX-003 runner 9 - фільтри без перезавантаження.html` (ця ж папка) · Статус: **чекає погодження власника**.
Основа: живий стан після runner 7 (C · фінал) і runner 8 (два ряди нижче 992). Токени: `boostershop-ds.css` без змін.

## 1. Потік
- Зміна чекбокса, «×» на чипі, «Скинути все», сортування, клік по сторінці пагінації → `fetch` того самого URL, який стоковий модуль зібрав би для перезавантаження. Із відповіді замінюються: сітка товарів, пагінація, кількість у шапці. Потім `history.pushState` (Back через `popstate` повторює той самий fetch).
- Якщо одна відповідь ще не прийшла, а клієнт поставив нову галочку: попередній запит скасувати (`AbortController`), застосувати лише останній.
- Будь-яка помилка (мережа, не 200, немає контейнера сітки у відповіді) → `location.href = url`.
- Панель **не закривається** після галочки. Нижче 992 стан панелі (відкрита/закрита, які групи розгорнуті) зберігається між запитами, бо панель не перемальовується.

## 2. Розмітка шапки категорії (порядок у DOM)
`H1 + кількість` → ряд (підкатегорії · «Фільтр» · сортування) → `#fpanel` (якщо відкрита) → **рядок чипів** (якщо є вибрані) → кінець картки.
Рядок чипів завжди останній у картці, і при відкритій, і при закритій панелі. Тому нові чипи не зсувають панель.

Тап: закрити панель (`aria-expanded=false`), прокрутити до верху сітки (−12 px), фокус на контейнер сітки. Під час запиту текст «Оновлюємо…» + спінер, `aria-disabled="true"`.
- **Завантаження:** сітка й пагінація `opacity:.45; pointer-events:none`, смужка 3 px `--bs-blue` над сіткою (indeterminate), на сітці `aria-busy="true"`. Висоту сітки фіксувати на час заміни (`min-height` = поточна), після вставки зняти. Шапка й панель не рухаються.
- **Порожньо:** замість сітки біла картка (`--bs-r`, рамка `--bs-line`): заголовок, текст, кнопка «Скинути фільтри» (secondary, рамка/текст `--bs-blue`). Липка кнопка в цьому стані стає рядком «0 товарів з цими фільтрами» + кнопка «Скинути».
- **Лічильники:** бейдж на «Фільтр» і лічильники груп оновлюються одразу після галочки (клієнтська сторона). Кількість у шапці, у липкій кнопці й у «Знайдено N» береться з відповіді сервера (той самий елемент, що рендерить «48 товарів»). Лічильники підкатегорій не чіпати.
- Зелений колір у цій зоні не використовується. Вид перемикання список/сітка лишається прихованим.

## 4. Копія (точно)
- Множина: `1 товар · 2–4 товари · 5–20 товарів · 21 товар · 22 товари · 11–14 товарів` (правило: n%10==1 && n%100!=11 → «товар»; n%10∈2..4 && n%100∉12..14 → «товари»; інакше «товарів»).
- Чипи: підпис `Фільтр:` · чип = назва значення · `Скинути все` (тільки якщо вибрано ≥ 2).
- `aria-label` чипа: `Прибрати фільтр «{значення}»`.
- Липка кнопка: `Показати {N} {товар|товари|товарів}` · `Оновлюємо…` · порожньо: `0 товарів з цими фільтрами` + `Скинути`.
- Низ панелі (≥ 992): `Знайдено {N} {…}` · `Оновлюємо…` · `Нічого не знайдено` · кнопка `Згорнути`.
- Порожній стан: `Нічого не знайдено з цими фільтрами` / `Приберіть один із фільтрів або скиньте всі.` / `Скинути фільтри`.

## 5. Клавіатура і скрінрідер
- Один прихований `role="status" aria-live="polite"` у шапці категорії. Оголошується тільки результат, коли прийшла відповідь:
  - `Знайдено {N} {…}.` / `Нічого не знайдено з цими фільтрами.`
  - після «×»: `Фільтр «{значення}» прибрано. ` + результат
  - після «Скинути все»: `Фільтри скинуто. ` + результат
  - після сортування: `Відсортовано: {текст опції}.`
  - «Показати ще» (якщо є): `Додано {N} {…}.`
- Фокус: галочка → лишається на чекбоксі · «×» → наступний чип, якщо немає — попередній, якщо немає — «Фільтр» · «Скинути все» / «Скинути фільтри» → «Фільтр» · «Показати N» і пагінація → контейнер сітки (`tabindex="-1"`, `aria-label="Товари"`).
- «Фільтр»: `aria-expanded`, `aria-controls="…панель…"`. Заголовок групи — `<button aria-expanded>`. Лічильник групи має `aria-label="вибрано N"`, бейдж на «Фільтр» має `aria-hidden` (кількість і так звучить у чипах).
- Фокус-рінг: `outline:2px solid var(--bs-blue); outline-offset:2px`. Для чекбоксів рінг на візуальному боксі.

## 7. BUG-004 A — бейдж кошика (окремий runner)
- 390 і 768 (до 991 включно). **Десктоп ≥ 992 — бейджа немає** (рішення власника 06.10: досить суми «Мій кошик - ₴…»). Кнопка 44×44 (768: з сумою), фон без змін. Порожній — бейджа немає. 1–9 — цифра, ≥10 — `9+`. Число = сума кількостей товарів у кошику.
- **Погоджено власником 06.10: варіант A.**
  - A: всередині кнопки, `top:3px; right:3px`, 16 px, фон `#fff`, цифра `--bs-green-hover`, 10.5/800. На 768 — на куті іконки кошика (`top:-7px; right:-9px` від іконки).
- `aria-label` кнопки: `Кошик: {N} {товар|товари|товарів}`, порожній — `Кошик порожній`. 768: `Кошик: N …, {сума}`. Бейдж `aria-hidden="true"`. Оновлювати разом з мінікошиком після додавання (подія, яку вже слухає RD-12). Шухляду не чіпати.
