# Codex Report — R-13.5: Nova Poshta display fallback

Date: 2026-07-25

## Scope

Owner QA reported a bare `—` when Nova Poshta cannot calculate a numeric tariff
because product dimensions or weight are missing/invalid. The patch keeps the
existing display-only shipping contract and replaces the empty state with the
explicit text `За тарифами Нової пошти`.

Evidence source:

- `booster-debug-R135-cart-refresh.tar.gz`
- SHA256: `0998fc1e0e2e3165707b7db57613f3a196b47305feebb804123513632a2c7ccb`

No parcel-dimension aggregation algorithm, payable order total, DB, settings,
payment, order-write, or external API contract is changed.

## Side effects / risks

- No DB or order-write changes.
- This patch deliberately does not repair unrealistic quantity-based parcel
  aggregation; it only makes the non-calculable tariff state explicit.
- Browser cache busting is supplied by the companion mini-cart checkout patch;
  both patches are intended to be deployed in the provided order.
