# Booster Shop — Merchant / Schema QA

## When to use
Use for Product schema, Merchant Center feed, shippingDetails and return policy structured data QA.

## Hard rules
- Do not invent GTIN. If missing, omit the field.
- Do not invent reviews or aggregateRating. Use only real review sources with links.
- Use brand / manufacturer only when confirmed. Otherwise omit.
- Do not add claims like `100% original`, `official distributor` or guarantees without legal proof.
- Keep product traits like sealed, unweighed, no sorting in FAQ / characteristics, not fake schema fields.
- Do not auto-add `sale_price`, `google_product_category` or `availability_date`. Use only in controlled staging tests.
- Do not change Merchant feed without reason.
- Never change product `id` in feed.
- `price` must always include currency. Currency: `UAH`.
- `availability` must use exact allowed values only: `in stock`, `out of stock`, `preorder`, etc.
- `shippingDetails` and `hasMerchantReturnPolicy` must match real legal policy.

## Output format
1. What changes in schema / feed
2. Fields requiring real data + source
3. Fields to omit due to missing data
4. Specific deindex / disapproval risks
5. Test set: 3–5 SKU for staging
6. Rollback plan
7. QA checklist

## Acceptance criteria
- No invented GTIN
- No reviews / ratings without source
- Price + currency match between site and feed for test SKU
- `availability` is valid for test SKU
- Rich Results Test passes on staging for all test SKU
- No new Merchant Center errors / warnings after push

## QA checklist
- [ ] No invented GTIN
- [ ] No reviews / aggregateRating without source
- [ ] `priceCurrency` / currency is `UAH`
- [ ] `availability` uses allowed values
- [ ] Rich Results Test passes on staging for 3–5 SKU
- [ ] Merchant Center diagnostics show no new errors / warnings after push
- [ ] Shipping / return policy text is legally accurate if touched
- [ ] Feed product `id` unchanged

## Risks
- Merchant disapproval → Shopping / Free Listings loss
- Schema spam → Google manual action
- Site/feed price mismatch → automatic suspension
- Fake reviews / GTIN → trust and compliance risk
