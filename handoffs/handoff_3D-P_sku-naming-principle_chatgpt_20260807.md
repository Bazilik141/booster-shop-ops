## Навіщо цей документ

Booster Shop розширює асортимент 3D-друкованих товарів (брелоки, фігурки, функціональні аксесуари). Щоб CRM могла коректно розпізнавати товари, а картки товару були послідовними й безпечними з юридичної точки зору, узгоджено єдиний принцип побудови артикулу (SKU) і назви товару.

**Збережи цей документ як постійне правило для Booster Shop 3D-друку.** Це не разовий список — це принцип, який ти застосовуєш до КОЖНОГО нового товару лінійки, включно з тими, яких ще немає в таблиці внизу. Таблиця в кінці — це вже узгоджені приклади (не змінювати), а розділи 1-4 — логіка, за якою визначаєш SKU і назву для всього нового.

---

## Частина 1 — Формула артикулу (SKU)

```
<ПРЕФІКС>-<МНЕМОНІКА>-<XYZ>
```

**ПРЕФІКС** — тип виробу, фіксовано три варіанти:
- `BR-` — брелок/підвіска
- `FIG-` — самостійна фігурка
- `ACC-3D-` — функціональний аксесуар (підставка, кейс, дек-бокс, світильник тощо)

**МНЕМОНІКА** — короткий код персонажа/теми, **не більше 5 символів**, читабельний. Дропай голосні/зайві літери так, щоб лишалась впізнавана частина слова (`JIGGLYPUFF` → `JIGGL`, `GEODUDE` → `GEOD`, `POKEBALL` → `PKBL`). Не обрізай довільно з середини слова.

**XYZ — три цифри, кожна свій рівень:**
- **X (сотні)** — категорія в межах префікса. Категорії йдуть кратними 10 (100, 200, 300…) — сусідні числа (200/210) НЕ використовуються для різних категорій, кожна нова категорія — нова сотня.
- **Y (десятки)** — підтип/модель у межах категорії (наприклад: розмір-лінійка мала/середня/велика → 1/2/3; колір-група → 0/1).
- **Z (одиниці)** — варіант у межах підтипу (розмір M/L, сумісність бренду тощо). За замовчуванням `0`.

**Приклад:** `ACC-3D-PKM-130` = функціональний аксесуар, тема Pokémon (загальна, без конкретного персонажа), категорія 1 (підставка для карток), підтип 3 (велика), варіант 0.

### Легенда категорій — FIG-

| X__ | Категорія |
|---|---|
| `1__` | Фігурка-в-покеболі / капсула-тип |
| `2__` | Статична декоративна фігурка |
| `3__` | Модель-кіт на литнику (збірна плата) |
| `4__` | Пласка настінна форма (силует / панно / картина) |
| `5__` | Рухома (wobble) фігурка |

### Легенда категорій — BR-

| X__ | Категорія |
|---|---|
| `1__` | Звичайний брелок-підвіска |
| `2__` | Брелок-клікер (fidget) |
| `3__` | Набір брелоків (кілька виробів в одному товарі) |

### Легенда категорій — ACC-3D-

| X__ | Категорія |
|---|---|
| `1__` | Підставка для карток |
| `2__` | Підставка під грейджені слаби, без покебола |
| `3__` | Підставка під грейджені слаби, на ніжці |
| `4__` | Побутовий аксесуар (стакан, цукерниця, підставка під телефон тощо) |
| `5__` | Світильник |
| `6__` | Пласкі пластикові аксесуари (закладки тощо) |

## Частина 2 — Формула назви товару

```
{Тип виробу} {Персонаж/Тема} ({Франшиза})[, {варіант}] — 3D-друк
```

**{Тип виробу}** — людський відповідник категорії SKU:

| Категорія SKU | Тип виробу в назві |
|---|---|
| `FIG- 100` / `FIG- 500` | Фігурка |
| `FIG- 200` | Фігурка (статична) |
| `FIG- 300` | Фігурка-конструктор |
| `FIG- 400`, підтип 0 | Панно |
| `FIG- 400`, підтип 1 | Картина |
| `BR- 100` | Брелок |
| `BR- 200` | Брелок-клікер |
| `BR- 300` | Набір брелоків |
| `ACC-3D- 100` | Підставка для карток |
| `ACC-3D- 200` / `300` | Підставка для грейджених карток (на ніжці) |
| `ACC-3D- 400` | залежить від конкретного виробу — назви окремо |
| `ACC-3D- 500` | Світильник |
| `ACC-3D- 600` | Закладка |

**{Персонаж/Тема}** — повне ім'я українською (не мнемоніка з SKU).

**({Франшиза})** — `(Pokémon)` / `(One Piece)` тощо, **у дужках, ПІСЛЯ персонажа, ніколи на початку назви.** Це не стилістика, а свідоме юридичне рішення — див. розділ 4, пункт 1. Обов'язково дотримуватись.

**[, {варіант}]** — розмір/колір/механіка, лише якщо реально відрізняє цей SKU від інших SKU того самого персонажа. Не додавай варіант, якщо в лінійці персонажа немає інших варіантів — це лише захаращує назву.

**— 3D-друк** — фіксований суфікс, завжди в кінці.

**Приклад:** «Брелок Чармандер (Pokémon) — 3D-друк», «Фігурка Онікс, рухома (Pokémon) — 3D-друк».

## Частина 3 — Як визначити SKU/назву для НОВОГО товару

Коли отримуєш товар, якого немає в таблиці розділу 5:

1. **Визнач префікс** (BR-/FIG-/ACC-3D-) за типом виробу — однозначно за визначенням вище.
2. **Підбери мнемоніку** — новий персонаж/тема → новий короткий код за правилом розділу 1. Перевір, що цей код ще не використаний в таблиці розділу 5 для ІНШОГО персонажа.
3. **Визнач категорію (X)** — товар явно підпадає під одну з категорій легенди? Використай її номер. **Якщо жодна категорія не підходить** (принципово новий тип виробу) — **не вигадуй нову сотню сам**. Познач це в звіті власнику як відкрите питання з пропозицією (наприклад: «пропоную нову категорію FIG-6__ для [опис], бо жодна з наявних не підходить») і чекай підтвердження, перш ніж фіксувати SKU.
4. **Визнач підтип (Y) і варіант (Z)** — якщо це перший товар цього персонажа в цій категорії, підтип/варіант = 0. Якщо це варіант вже наявного товару (той самий персонаж, та сама категорія, відрізняється розміром/кольором) — наступна вільна цифра в межах уже зайнятого підтипу/варіанта того самого персонажа (звіряй з таблицею розділу 5, щоб не задублювати номер).
5. **Побудуй назву** за формулою розділу 2, підставивши правильний «Тип виробу» з таблиці категорій.
6. **Перевір заборони** — розділ 4, всі пункти.

Якщо після цих кроків лишається сумнів (наприклад: товар межує між двома категоріями, або незрозуміло, чи вважати щось «варіантом» чи «новим товаром») — постав питання власнику прямим текстом замість здогадки. Це узгоджений принцип роботи з цим проєктом: не вигадувати, коли є неоднозначність.

## Частина 4 — Заборони (юридичний ризик, не стилістика)

1. **Франшиза ніколи не веде назву.** «Pokémon Фігурка Онікс…» — так називаються офіційні ліцензійні товари. Наші 3D-друковані вироби — не офіційна продукція правовласника, а власне виробництво Booster Shop на тему персонажа. Використання тієї ж граматичної конструкції підвищує ризик сприйняття як заяви про партнерство/ліцензію. Франшиза — тільки в дужках, після персонажа.
2. **Ніколи не писати про офіційність, ліцензію чи партнерство з правовласником.** Якщо потрібно згадати франшизу в описі (не лише в назві) — тільки як тематичне пояснення («тематика Pokémon», «сумісний з картками Pokémon TCG»), не як заяву про походження товару.
3. **Не називати «іграшкою».** Усі колекційні/декоративні 3D-вироби — 14+, навіть із рухомими елементами (шарнір, клікер, wobble-механізм). Механіка може бути описана як цікава функція, але не в рамці «дитяча іграшка».
4. **Не вигадувати характеристики.** Розмір, вага, матеріал, точний час виготовлення — тільки реальні дані, надані власником. Якщо дані відсутні — залиш поле явно позначеним як відсутнє, не підставляй правдоподібне число.
5. **Не вигадувати GTIN, відгуки, рейтинги, кількість відгуків.** Цих даних не існує для власноруч виготовлених товарів — не заповнювати.
6. **Природні технологічні особливості 3D-друку** (видимі шари, незначні сліди підтримок, невеликі відмінності відтінку між партіями) — описувати чесно, не приховувати і не драматизувати.
