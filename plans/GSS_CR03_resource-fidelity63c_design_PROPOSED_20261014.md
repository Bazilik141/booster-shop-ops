## F1: option-A context-free escape-decoded byte screening (B1/N1)

Keep the existing whole-byte finite screen with escapeAware:true. Add the SAME policy's linear context-free escape-decoded view for BOTH public BYTE_FALLBACK streams, including stderr alongside normal JSON stdout. This does not change ORIGINAL byte redaction: no mapped encoded masks, original spans, markers or original budget semantics change. Screen the added view with escapeAware:false and the exact existing allowlist. Any non-allowlisted hit, including screen-counter saturation, yields PUBLIC_COPY_SCREEN_REFUSED for the whole copy. No C/hash/pin/result promotion and no repeat.

The view is generated by one forward cursor, from original public bytes only, independent of quotes, token validity, envelope validity and raw newlines. Recognized simple escapes are quote, backslash, slash, b, f, n, r, t. For a maximal backslash run of length n, emit floor(n/2) literal backslashes; if n is odd, the remaining backslash may introduce one recognized simple escape or u followed by exactly four ASCII hex digits. Decode that unit to UTF8. Adjacent escaped high/low surrogate units combine to their scalar; an unpaired escaped surrogate becomes U+FFFD as Buffer.from of the corresponding JS string does. For an odd unknown/malformed escape or a dangling backslash, retain the remaining backslash and unconsumed bytes literally. Never recursively decode emitted bytes. Even backslash runs leave the following u/escape letter literal. All other original bytes, including invalid raw UTF8 in a labelled malformed byte stream, pass through; no lenient envelope parse or Unicode-normalization claim.

The output byte count is <= input byte count: literal bytes/pairs do not expand, every simple escape shrinks, a six-byte Unicode escape emits <=three bytes, and a twelve-byte pair <=four. Allocate at most that already approved stream cap, with a checked cursor. Release each view before making the next. No array of per-token values, per-byte origin maps, quote pairing, repeated suffix scanning or per-token regex overhead; total view construction/scanning is linear under the accepted finite cursors. Raw and decoded screening budgets are public-only and distinct from ORIGINAL transformation charges. Retaining the raw screen is intentional: it keeps its existing escapeAware behavior, while the extra view can only add refusals. A hit already refuses, so duplicate detection across the two views cannot create a successful artifact or expand the original budget.

The public-only validator below owns this entire predicate and is called by the worker producer, runtime parent and public provenance. Worker-generated invalid artifact failures other than the fixed nine worker refusal codes remain protocol/mechanism defects, never a wider worker enum. Option-A decoded hits use the existing allowed worker PUBLIC_COPY_SCREEN_REFUSED code. The stronger screen is finite assurance only; arbitrary encodings, malformed unknown escapes, confusables and privacy absence remain unproved.

Stdout mode remains PASS iff JSON_ENVELOPE; MALFORMED_OR_INCOMPLETE iff BYTE_FALLBACK; withholding iff NOT_ATTEMPTED_WITHHELD. Parent BYTE stdout still strict-parses: valid unique JSON is invalid as byte mode; JSON_SYNTAX/JSON_DUPLICATE can remain labelled malformed and never usable stdout. This allows a genuine later-syntax-error original where byte masks collide into duplicate marker keys. Independently detected ORIGINAL duplicate still refuses RAW_STDOUT_DUPLICATE before any copy. Refuse BYTE_FALLBACK_AFTER_JSON_ERROR in BOTH streams, with no fallback override. Withheld empty bytes keep their exact count/reason predicates.
