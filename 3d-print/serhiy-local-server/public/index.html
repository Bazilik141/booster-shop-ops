    Калькулятор партії

    Чернетка зберігає п’ять введених значень для SKU. У Номенклатуру потрапляють лише значення за одиницю: сумарні вага й час діляться на кількість партії.

    Оберіть SKU: сервер завантажить його чернетку. Потім введіть або перевірте дані й натисніть «Розрахувати».

    Фурнітура — окремо після друку

    У SKU зберігається ціна обраної фурнітури. Вона не блокує базовий розрахунок партії.
