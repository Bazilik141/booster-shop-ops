# Встановлення Booster 3D на комп'ютер Сергія

## Що передати Сергію

Передай один фінальний ZIP-архів і окремий файл `ІНСТРУКЦІЯ ДЛЯ СЕРГІЯ.txt`. Не надсилай токен у месенджері разом з архівом. Найкраще ввести адресу й токен особисто під час першого запуску.

Сергію не потрібно встановлювати Node.js або інші програми: потрібний рушій уже лежить усередині архіву.

## Перед початком

- Windows 10 або Windows 11, 64-біт.
- Робоче підключення до інтернету.
- Власник має окремий `BOOSTER_3DP_SERHIY_TOKEN`, не owner-токен.
- Власник має актуальну HTTPS-адресу 3D-P Apps Script Web App, яка закінчується на `/exec`.

## Встановлення

1. На комп'ютері Сергія натиснути правою кнопкою на ZIP-архіві та обрати **«Видобути все»**.
2. Розпаковану папку залишити в постійному місці, наприклад у `Документи\Booster 3D Сергій`.
3. Відкрити розпаковану папку. Не запускати `.bat` безпосередньо з вікна ZIP-архіву.
4. Двічі натиснути **«Запустити.bat»**.
5. Під час першого запуску вставити HTTPS-адресу Web App, натиснути Enter, потім вставити окремий токен Сергія та знову натиснути Enter. Символи токена не відображаються.
6. Дочекатися автоматичного відкриття сторінки `http://127.0.0.1:3107/` у браузері.
7. За бажанням створити ярлик: права кнопка на `Запустити.bat` → **«Надіслати» → «Робочий стіл (створити ярлик)»**.

## Перевірка після встановлення

У браузері мають бути:

- заголовок `Booster 3D — Сергій`;
- непорожня кількість активних SKU;
- актуальна кількість товару на складі;
- вкладки `Калькулятор`, `Вироби`, `Інформація`;
- статус успішного отримання даних без повідомлення про відсутність зв'язку.

На першій перевірці достатньо відкрити вкладки й переглянути дані. Не створювати тестові записи у живій таблиці без окремо погодженого тестового SKU.

## Поточне оновлення без повторного налаштування

Цей реліз є переносною папкою, а не автоматичним EXE-оновлювачем. Для наступної версії:

1. Закрити вкладку Booster 3D і зачекати приблизно п'ять хвилин, щоб локальний сервер зупинився.
2. Розпакувати новий ZIP в окрему нову папку.
3. Запустити в новій папці `Запустити.bat`.
4. Адреса й токен зберігаються в профілі Windows, тому їх повторне введення зазвичай не потрібне.
5. Перевірити завантаження даних і лише після цього видалити стару папку.

Автоматичний EXE-оновлювач є окремим наступним компонентом і до цього архіву не входить.

## Якщо щось пішло не так

- Якщо токен відхилено: запустити `Змінити токен.bat` і ввести новий токен Сергія.
- Якщо сторінка не відкрилася: перевірити інтернет, переконатися, що архів повністю розпаковано, і повторити запуск.
- Якщо Windows показала повідомлення про відсутні файли: не переносити окремі файли з папки; розпакувати архів заново.
- Якщо помилка повторюється: зупинитися й надіслати власнику знімок повідомлення. Токен не показувати й не фотографувати.

## Критерій успіху

`Запустити.bat` відкриває сторінку, дані завантажуються, склад показує актуальне значення, а повторний запуск не просить адресу й токен знову.
